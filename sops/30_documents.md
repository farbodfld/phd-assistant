# Documents

- One folder per position: "<Project short title> -- <Country> -- <Supervisor> (<University>)".
- Every file is versioned; the folder keeps what was actually sent.
- Master CV: copy into the folder, never edit per position.
- Transcripts: MSc HEAR (compressed under 2 MB) and BSc transcript, plus certificates if asked.
- Personal statement / letter of application: written for the specific project. Structure:
  motivation for this project, relevant academic foundation (real marks), research experience
  (MSc dissertation, BSc thesis), software engineering experience, why this group, close.
- Research proposal: follow the advert's length limit; title, background, aims, methods,
  expected contributions, timeline, references only if real.
- Universities that ban AI-written statements (institutions.yaml ai_writing: banned): produce a
  reference draft marked "REFERENCE DRAFT. DO NOT SUBMIT." and tell Farbod he must write his own.
