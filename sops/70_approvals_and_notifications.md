# What needs Farbod, and how to ask

| Action | Level |
|---|---|
| Reading, scraping, tracker updates, drafting | automatic |
| Sending any email | Approve in Telegram |
| Triggering reference requests, final Submit, payment, login | Farbod only |
| Choosing between options under a limit (e.g. Oxford courses) | decision buttons in Telegram |

Flag actions:
- inform: tell him in the daily report.
- followup: the agent acts itself (e.g. adds a funding question to the email) and tells him.
- decide: ask him with buttons; remind him before the deadline if unanswered.
- block: stop; explain why (e.g. AI-written statement for Oxford).

Every daily report ends with "Not checked today" listing anything skipped and why.
